GIFA 原神跟跑助手 0.2.6（Windows x64 绿色版）
================================================

首次运行会弹「Windows 已保护你的电脑」？
----------------------------------------
会。这是因为发布包**没有代码签名**，Windows SmartScreen 对"没签名 + 没下载量"的新程序
默认拦截，不是杀毒报毒。三种处理方式，任选一种：

1. 点弹窗里的「更多信息」→「仍要运行」。
2. 先解除锁定再运行（推荐，以后不再重复弹）：
       PowerShell:  Unblock-File .\GIFA.exe
3. 想确认文件没被篡改，校验哈希：
       PowerShell:  Get-FileHash .\GIFA.exe -Algorithm SHA256
   与同目录 SHA256SUMS.txt 里那一行对比，一致即可放心运行。

为什么不签名：正规的代码签名证书要企业资质或付费服务，本项目是个人开源项目。
细节和可选方案见仓库 docs/SIGNING.md。

用法
----
1. 双击 GIFA.exe。首次运行会请求管理员权限（原因见下）。
2. 点标题栏的「换链接」，粘贴 B 站攻略视频链接后回车；或直接在地址栏输入。
3. 点「标定」，把金色圆环套住视频里的小地图。
4. 游戏请使用「窗口化」或「无边框窗口」。独占全屏会把浮窗完全盖住，这是 Windows 的显示模型限制，不是 bug。

默认热键
--------
Alt+Space     播放 / 暂停
Alt+← / →     后退 / 前进 5 秒
Alt+↑ / ↓     上一 P / 下一 P
Alt+I         纯视频沉浸（再按一次退出）
Alt+H         显示 / 隐藏浮窗
Alt+S         循环倍速
Alt+O         透明度
F8            按住临时加速
手柄          按住 L3 弹出八方向圆盘，右摇杆选方向，松开触发

为什么需要管理员
----------------
Windows 的低级键盘钩子只能收到「前台窗口完整性级别不高于自己」的按键。
游戏若以管理员运行，不提权的浮窗一个热键都收不到 —— 这是 UIPI 规则。

数据位置
--------
绿色版：GIFA.exe 同级的 data\ 目录（删掉整个文件夹即完全卸载）
安装版：%APPDATA%\原神跟跑助手\

依赖
----
Microsoft Edge WebView2 运行时（≥110）。Windows 11 自带；Windows 10 缺失时启动会提示下载地址。
