# 发布说明 v0.3.0（2026-11-22）

> 这是 Rust 复刻版的第一个**能日常用**的版本：拿它跟着 B 站攻略视频跑图，
> 或者在真实游戏里单独用（采游戏窗口 + 屏幕叠加）。

---

## 这个版本能做什么

### 1. 跟着视频跑图（主力用法）

* 贴 BV 号/链接就能放（真 WebView2 里的真 B 站页面，登录态、观看进度都保留）
* 浮窗可以置顶/半透明/拉边缩放，`Alt+I` 一键沉浸（只剩视频）
* 识别从画面里读小地图：**行进方向**（青色箭头）+ **镜头朝向**（白色扇形）
* 两路角度画成叠加层：红箭头 = 行进方向，绿弧 = 视野范围

### 2. 在真实游戏里用（本次新增）

```powershell
gifa-demo.exe --game 300 --autocenter
```

* 自动找到游戏窗口（`UnityWndClass`），采它的客户区，不再需要视频
* 浮窗自动隐藏，只留一个透明叠加层贴在游戏的小地图上
* `--autocenter` 会自己找小地图圆心（找不到就重试，收敛后写进布局）

### 3. 其它

* 10 条全局热键（组合键走 `RegisterHotKey`，单键/侧键/按住类走低级钩子）
* 手柄 L3 呼出八方向圆盘
* 布局标定（把圆环拖到小地图上，支持多套布局、内置两套）
* 设置与原版 `settings.json` 同构，旧版设置能直接搬过来

## 实测数据

| 场景 | 结果 |
|---|---|
| 视频素材（蒙德 1080p，**138 帧人工真值**） | 箭头 138/138，误差中位 **0.03°**、最大 2.35° |
| 真实游戏（2560×1440 绿地，**5 分钟长跑**） | 箭头 **2989/3004（100%）**、视锥 98% |
| 性能 | 截帧 11.4ms / 检测 1.0~1.2ms，全程无漂移 |
| 资源 | 内存 24→25MB、CPU 2.7% 单核、线程/句柄无增长 |
| 自检门禁 | 18 项全过；`cargo test` 130 通过 |

方向精度对标方式：真人逐帧标注（标注工具见 `docs/VISION.md`），
Rust 输出与标注比对 —— 不是"看着差不多"。

## 已知限制（边界，不是待修 bug）

| 限制 | 说明 |
|---|---|
| **低对比度地图失效** | 冰原/雪地这类整片浅青的底图上，箭头和底色分不开（算法判据本身如此）。绿地、璃月、须弥正常 |
| **必须无边框全屏或窗口化** | 独占全屏拿不到画面（GDI 截到黑帧），这是 Windows 层面的限制 |
| **游戏以管理员运行时热键失灵** | UIPI 限制：非提权进程的低级钩子收不到提权窗口的按键。发布版清单要求提权，请用它 |
| **图标密集时偶发单帧偏移** | 小地图图标和箭头粘成一块时，退回"六边形兜底"，兜底约 5% 的帧会偏；时序滤波吃掉 89%，实际约 0.6% 的帧会闪一下 |

## 与原版的关系

* 识别算法是**逐步骤移植**，并用原版 JS 做过逐帧对拍（33 帧**角度差 0.0000°**、
  时序层 240 步逐帧一致）。对拍工具在 `tools/vision-ref/`，运行时从原版源码切算法段。
* 复用原版 `src/renderer`、`src/console` 的 HTML/CSS（GPL-3.0 同源）。
* 与原版有意不同的地方，全部有真机数据支撑，记录在 `README.md` 的 M8b 一节
  和 `docs/VISION.md`。

## 装

* 安装包：`gifa-rs/dist/GIFA-Setup-0.3.0.exe`（当前用户安装，不写 HKLM；
  卸载默认保留 `%APPDATA%\原神跟跑助手`）
* 便携版：`gifa-rs/dist/GIFA-0.3.0-win64.zip`（解压即用）
* 需要 WebView2 运行时 ≥110（Win11 自带；Win10 用安装包里的引导或手动装）

首次启动位置在**工作区左下角**（720×450）——刻意避开游戏左上角的小地图，
否则采样窗会截到自己的窗口。窗口位置/尺寸会被记住。
